מערכת ליווי עבודות גמר

כלי חינוכי חינמי למורים בישראל, לליווי עבודות גמר של תלמידי תיכון: מועדים, משימות, הגשת קבצים, הערות ומשוב וציונים, במקום אחד ברור.

מה המערכת עושה

תכנון וגאנט

מחזור עבודות, משימות ומועדים בגאנט ובלוח שנה, כולל חופשות וחגים של משרד החינוך.

הגשה ובדיקה

תלמידים מגישים קבצים, והמורה בודק, כותב הערות, מנקד לפי מחוון ומפרסם משוב וציון.

שקיפות לתלמיד

כל תלמיד רואה את המשימות, ההערות והציון שלו בלבד.

למי זה מיועד

למורים שמלווים עבודות גמר בבית הספר התיכון, ולתלמידים שלהם. התלמיד נכנס רק אם המורה רשם אותו.

איך הפרטיות נשמרת

לכל מורה שרת פרטי משלו, בחשבון Google שלו. שמות תלמידים, עבודות, הערות וציונים נשמרים ב-Google Drive של המורה ולא אצל מפעיל האתר. מפעיל האתר אינו מחזיק מסד נתונים, ואינו רואה נתוני מורים או תלמידים. פירוט מלא במדיניות הפרטיות.

למה ההקמה מבקשת גישה לחשבון Google

בהקמה חד-פעמית, בדפדפן של המורה, המערכת יוצרת בחשבון Google של המורה את השרת הפרטי שלו: פרויקט Apps Script, גרסה ופריסה, ופרויקט Google Cloud אישי שמאפשר לשרת להתעדכן בעצמו בגרסאות חתומות. ההרשאות נשארות בזיכרון הדף בלבד, ואינן נשמרות או נשלחות למפעיל. את הגישה אפשר לבטל בכל עת ב-myaccount.google.com/permissions. הסבר מפורט על כל הרשאה נמצא במדיניות הפרטיות ובמדריך.

Thesis Project Guidance System

A free educational tool for Israeli high-school teachers to guide students' thesis projects: schedules, tasks, file submissions, comments, feedback and grades in one place.

  • Who it is for. Teachers who supervise thesis projects, and their students. A student can sign in only if the teacher registered them.
  • Your data stays yours. Each teacher runs their own private server in their own Google account (Google Apps Script). Student names, submissions, feedback and grades are stored in the teacher's own Google Drive. The operator has no database and cannot access teacher or student data.
  • Why setup asks for Google access. In a one-time setup, run in the teacher's browser, the system creates the teacher's own Apps Script project, version and deployment, and a personal Google Cloud project that lets the server install signed updates to itself. Tokens stay in browser memory only and are never stored or sent to the operator. Access can be revoked at any time at myaccount.google.com/permissions.
  • Operator. אורי העליון, a biology and health-sciences teacher in Israel. Contact: uribyology@gmail.com.
